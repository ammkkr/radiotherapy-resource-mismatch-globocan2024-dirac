# Data Use

This repository contains derived analysis-ready files and figure source data
created from public aggregate data sources.

## Source Data

- Global Cancer Observatory Cancer Tomorrow was used for projected country-level
  cancer incidence and mortality. The extracted API data version was 2024.
- IAEA Directory of Radiotherapy Centres (DIRAC) was used for country-level
  radiotherapy-resource variables.
- Natural Earth country geometry was used for the world map.

## Derived Files

Derived CSV files in `data/` are provided to support peer review,
reproducibility, and figure/table verification. DIRAC-derived variables should
be reused only in accordance with IAEA DIRAC data-use and citation guidance.
